## Overview

This library contains carefully crafted prompts for AI tools like ChatGPT, Claude, and others to help developers, engineers, and IT professionals solve common problems more efficiently. Each prompt is designed to produce consistent, high-quality results for specific tasks.

## Why Use These Prompts?

- **Save Time**: Stop rewriting the same prompts repeatedly
- **Improve Results**: Use prompts engineered for optimal AI responses
- **Learn Best Practices**: See examples of effective prompt engineering
- **Contribute Knowledge**: Share your expertise with the community

## Categories

- [Development](./prompts/development/README.md) - Language-specific prompts for debugging, refactoring, and coding
- [DevOps](./prompts/devops/README.md) - Prompts for CI/CD, infrastructure, and operations
- [Architecture](./prompts/architecture/README.md) - Prompts for software design patterns and system architecture

## Quick Start

1. Browse the [prompts directory](./prompts) to find a prompt that fits your needs
2. Copy the prompt and replace placeholders (text between `{curly braces}`)
3. Paste into your preferred AI tool (ChatGPT, Claude, etc.)
4. Get results and iterate if needed
